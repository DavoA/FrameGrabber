# Кадры из видео (FrameGrabber)

Android-приложение по мотивам codeshack.io/video-thumbnail-generator: достаёт кадры из видео — по одному или пачкой с интервалом.

## Что умеет
- Выбор видео из файлов или «Поделиться» из галереи
- Превью кадра, ползунок, лента-раскадровка, ввод времени (`12.5`, `1:23.5`), шаг ±1 кадр
- Размер: оригинал / 1280×720 / 1920×1080 / свой (с полями, как на сайте)
- Формат: JPG / PNG / WebP + качество
- Пакетный режим: **каждые N секунд** или **N кадров равномерно**, с диапазоном «с … по …»
- Сетка снятых кадров: поделиться, сохранить, перейти к моменту, удалить
- Всё в галерею (`Pictures/FrameGrabber`) или одним ZIP в `Загрузки/FrameGrabber`

Работает офлайн, без библиотек, Android 10+. Декодирует видео через кодеки телефона, поэтому HEVC/H.265 и MKV обычно тоже открываются.

## Как собрать
1. Установить Android Studio.
2. File → Open → папка `FrameGrabber`. Дождаться Gradle Sync (если Studio предложит обновить AGP/Gradle — можно соглашаться).
3. Подключить телефон по USB с включённой отладкой → Run ▶.
   Или Build → Build APK(s) → APK в `app/build/outputs/apk/debug/`, его можно скинуть на телефон и установить.

## Файлы
- `FrameEngine.kt` — извлечение кадров (MediaMetadataRetriever), масштабирование, кодирование, разбор времени
- `MainActivity.kt` — экран и вся логика
- `res/layout/header.xml` — разметка панели управления
